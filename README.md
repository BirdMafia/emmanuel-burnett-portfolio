# Emmanuel Burnett | Graphic Design Portfolio

This static site includes an animated EB masthead, a featured Ex Libris project, and a print layout. Open `index.html` in a browser or use GitHub Pages. No build step is required.

## Add the original artwork

Save Emmanuel's upright Ex Libris original as `assets/ex-libris-original.png` and commit it. The gallery will display the image automatically. Until the file is added, the site shows the project description.

Review any additional artwork with Emmanuel before placing it in this public repository. Keep the original artwork separate from AI-assisted presentation images and label any AI-assisted images shown. Include only contact details Emmanuel wants public.

## Handoff and publish

1. Emmanuel can fork this repository to his own GitHub account.
2. In the fork, open **Settings → Pages**. Under **Build and deployment**, select **Deploy from a branch**, then **main** and **/ (root)**.
3. Check the live URL and confirm the artwork displays on mobile. Use **Print / Save PDF** to export the résumé.
4. Add the live gallery URL to LinkedIn Featured and the résumé.
